# GeoScene Maps SDK for Javascript - Component Samples

This directory contains samples that demonstrate how to use web components and the core API from the GeoScene Maps SDK for JavaScript with various frameworks, module bundlers, and build tools. There are three component packages available.

Components from the SDK can be accessed through the GeoScene CDN or npm. To install npm, visit [https://www.npmjs.com/get-npm](https://www.npmjs.com/get-npm).

## Usage

To use a sample, navigate to its directory and follow the instructions provided in its README. The samples can also be downloaded using the links provided in the respective README files.
