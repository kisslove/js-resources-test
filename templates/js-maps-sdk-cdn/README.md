# GeoScene Maps SDK for JavaScript CDN template

📁 **[Click here to download this directory as a ZIP file](https://github/geoscene/jsapi-resources/zips/js-maps-sdk-cdn.zip)** 📁

This template demonstrates how to use the [GeoScene Maps SDK for JavaScript](https://doc.geoscene.cn/javascript/latest/) in a CDN application.

To quickly scaffold a new application using this template, run the following command in your terminal:

```bash
npx @geoscene/create -n my-geoscene-app -t cdn
```

`<script type="module" src="https://js.geoscene.cn/5.1/"></script>` will load all the necessary packages used in the template.

See the [Get started with CDN guide](https://doc.geoscene.cn/javascript/latest/web-components/get-started/#create-an-app-with-the-geoscene-cdn) for full setup instructions.
