# GeoScene Maps SDK for JavaScript Vite TypeScript template

📁 **[Click here to download this directory as a ZIP file](https://github/geoscene/jsapi-resources/zips/js-maps-sdk-vite.zip)** 📁

This template demonstrates how to use the [GeoScene Maps SDK for JavaScript](https://doc.geoscene.cn/javascript/latest/) in a Vite TypeScript application.

## Get started

To quickly scaffold a new application using this template, run the following command in your terminal:

```bash
npx @geoscene/create -n my-geoscene-app -t vite
```

This template uses the following packages:

- [`@geoscene/core`](https://www.npmjs.com/package/@geoscene/core)
- [`@geoscene/map-components`](https://www.npmjs.com/package/@geoscene/map-components)
- [`@geoscene/charts-components`](https://www.npmjs.com/package/@geoscene/charts-components)
- [`@geoscene/calcite-components`](https://www.npmjs.com/package/@geoscene/calcite-components)

## TypeScript

This template is configured to use TypeScript. If you prefer to use JavaScript, you can:

- Remove the `tsconfig.json` file
- Update the file extensions from `.ts` to `.js`
- Remove the `typescript` dependency from `package.json`
